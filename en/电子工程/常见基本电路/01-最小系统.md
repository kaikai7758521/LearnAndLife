# Takes STM32/ESP32 as an example. Minimum system principle notes
> Description: Minimum system = the simplest circuit that allows the chip **to be powered on, run stably, and download the program**. It does not include peripheral drivers.
Any MCU minimum system of > consists of four core modules: power circuit, reset circuit, clock circuit, download/debug circuit; ESP32 additionally includes Flash and enable circuit.

## 1. General concept of minimum system
The minimum system of a single-chip microcomputer is a basic circuit in which the chip is separated from external expansion peripherals and relies only on the minimum components to enable the chip to start up and run the code normally.
As long as any one of these core parts is missing, the chip will most likely be unable to start, fail to program, and run unstable.

General composition:
1. power supply + power filter
2. reset circuit (power on reset/manual reset)
3. external high-speed crystal oscillator (optional, the built-in RC in the chip can be replaced, but the accuracy is poor)
4. program download & debugging interface
5. BOOT startup configuration circuit (select startup mode)

## 2. STM32 minimum system (taking STM32F103C8T6 as an example)
STM32F103 is a classic Cortex‑M3 core MCU with a supply voltage of 3.3V.

### 1. Power circuit
Pins: `VDD`, `VSS` (main power supply), `VDDA`, `VSSA` (analog power supply, ADC, PLL)
- power supply: **3.3V**, direct connection to 5V is strictly prohibited
- decoupling capacitor (0.1μF ceramic capacitor, placed nearby VDD/VSS for each group)
  - function: filter out high-frequency noise from the power supply, suppress voltage fluctuations caused by the internal switch of the chip, and prevent the chip from crashing and the program from running away.
- 10μF electrolytic capacitor (power inlet)
  - function: low-frequency filtering, buffering the impulse current at power-on.
> specifications: Place a 0.1μF ceramic capacitor next to each power pin, and the capacitor should be as close as possible to the chip pin.
It is recommended that the > VDDA analog power supply be filtered separately to ensure the ADC sampling accuracy; a small magnetic bead can be strung together to isolate digital noise.

### 2. Reset circuit (NRST pin, low level reset)
Classic power-on reset + manual button reset:
- 10kΩ pull-up resistor: NRST is pulled to 3.3V by default → normal working state
- 0.1μF capacitor: The capacitor is equivalent to a short circuit at the moment of power-on. NRST is briefly pulled low and automatically resets after power-on; the capacitor returns to high level after charging is completed.
- reset button: connected in parallel to both ends of the capacitor, press to pull NRST low directly, manual reset
> principle: STM32 detects that NRST remains low for a period of time, the core is reset, and all registers return to their initial state; they start from the specified address after release.

### 3. Clock circuit (external high-speed crystal oscillator HSE)
Pin: `OSC_IN`, `OSC_OUT`
- 8MHz passive crystal oscillator (commonly used in F103)
- two 20pF load capacitors, connect both ends of the crystal oscillator to GND respectively
The function of - is to provide a high-precision reference clock for the chip PLL, and the chip is multiplied to the 72MHz main clock.
Optional for > : no external crystal oscillator is used, and the chip's internal HSI 8MHz RC oscillator is used. Disadvantages: large temperature drift, poor accuracy, not suitable for serial communication and USB.

> internal low-speed crystal oscillator LSI (internal): for independent watchdog and RTC; the external 32.768K crystal oscillator (LSE) is the RTC clock and does not belong to the simplest and smallest system and can be omitted.

### 4. BOOT boot selection circuit
The two pins BOOT0 and BOOT1 determine the chip startup address:
| BOOT1 | BOOT0 | Boot mode |
| ---- | ---- | ---- |
| 0 | 0 | Main flash memory boot (normal operation of user program, most commonly used) |
| 0 | 1 | System memory startup (ISP serial port download) |
| 1 | X | Built-in SRAM startup (for debugging) |

Circuit practice: BOOT0 uses a 10k pull-down resistor to be grounded by default (normal startup), and the reserved pin header/button can be pulled up to 3.3V to enter ISP downloading; BOOT1 is directly connected to ground with a 10k pull-down resistor.

### 5. Download and debug circuit
Two options:
1. **ST‑LINK (SWD, recommended)**: four wires `SWDIO`, `SWCLK`, GND, 3.3V.
   - SWDIO: serial data
   - SWCLK: Synchronous clock
Advantages of    - : only 2 signal lines, occupying few pins, supporting online debugging and single-step breakpoints.
2. **serial port ISP download (USART1)**: PA9(TX)/PA10(RX), with BOOT0 pulled high, use the serial port tool to burn.

> STM32F103 minimum system component list
> STM32F103C8T6, 8M passive crystal oscillator ×1, 20pF capacitor ×2, 0.1μF decoupling capacitor ×4, 10μF electrolytic ×1, 10k resistor ×3, reset button ×1.

## 3. ESP32 minimum system (ESP32‑WROOM‑32 module)
ESP32 dual-core Tensilica LX6, built-in Wi-Fi + Bluetooth; the module comes with SPI Flash, focusing on the CHIP_EN enable pin.

### 1. Power supply circuit
Module power supply: **3.3V, higher current requirement, peak value up to 300mA+ (when Wi-Fi is transmitting)**
- power inlet: large capacity 10μF + 0.1μF decoupling capacitor
Key to - : ESP32 RF operating current fluctuates greatly, so filter capacitors cannot be saved; a current margin must be reserved for the selection of voltage stabilizing chips (such as AMS1117‑3.3).
Pitfalls of > : Directly use the IO port of the microcontroller to power the ESP32. If the load is insufficient, it will restart repeatedly.

### 2. CHIP_EN (EN) enable pin
- 10k pull-up resistor to 3.3V: default high level, the chip is enabled and works normally
- can be connected to the reset button and pulled low: when EN is pulled low, the chip is reset after power-off, and it is released to power on.
> Many novices leave EN floating, and the chip cannot be started randomly. ESP32 does not have an independent NRST pin, **EN is the reset control pin**.

### 3. BOOT download pin (GPIO0)
GPIO0 determines the boot mode:
- GPIO0 = high level (floating/pull-up): boot from Flash and run firmware
- GPIO0 = low level: enter download mode (UART download)
Circuit: GPIO0 10k pull-up resistor, connect the button to GND; press and hold the button to power on when downloading.

> GPIO2: Some versions require pull-up, which has generally been processed internally in the module.

### 4. Clock
The ESP32‑WROOM‑32 module **has integrated a 40MHz crystal oscillator** inside. The minimum external system does not need to connect a crystal oscillator!
Only the > ESP32 bare chip ESP32‑D0WD requires an external 40M crystal oscillator + load capacitor, which is not required in the module solution.

### 5. Download circuit
ESP32 default UART0 download: TX0 (GPIO1), RX0 (GPIO3), with automatic download circuit (optional)
Automatic download circuit (added transistor): Realizes serial port DTR/RTS signal automatic control of GPIO0 and EN, no need to manually press buttons to download; the simplest and smallest system can omit the automatic circuit and use manual buttons.

### 6. Flash
The WROOM series module has a built-in 4MB SPI Flash, and there is no need to draw an external Flash circuit; the bare chip solution requires an external SPI Flash.

> ESP32 module minimum system component list
> ESP32‑WROOM‑32 module, several 0.1μF capacitors, 10μF electrolytic, 10k resistor ×2, buttons ×2 (EN reset key, GPIO0 download key), AMS1117‑3.3 voltage regulator (when inputting 5V).

## 4. STM32 minimum system VS ESP32 minimum system comparison
| Project | STM32F103C8T6 | ESP32‑WROOM‑32 module |
| ---- | ---- | ---- |
| Core | Cortex‑M3 | Dual Core LX6 |
| Typical power supply | 3.3V, small current | 3.3V, large RF peak current |
| reset pin | NRST, low reset | CHIP_EN(EN), low level turns off the chip |
| Boot Configuration | BOOT0/BOOT1 | GPIO0 |
| external crystal oscillator | requires an external 8M crystal oscillator | The module comes with a 40M crystal oscillator, no external crystal oscillator is required |
| Flash | Built-in Flash | The module comes with SPI Flash |
| debugging interface | SWD(ST‑LINK) | Only UART download, no native SWD debugging |

## 5. Summary of common pitfalls
1. decoupling capacitor is too far away from the chip → prone to crash and unstable power on
2. ESP32 has insufficient power supply → Restart after connecting to WiFi
3. BOOT pin is floating, the level is uncertain → randomly enters download mode
The 4. crystal oscillator load capacitance parameter is wrong and the crystal oscillator does not vibrate → the chip does not run.
Mixing 5. 3.3V and 5V directly burns the MCU
The EN pin of 6. ESP32 is left floating and the chip cannot be powered on stably.

## 6. Summary
The essence of the minimum system circuit: **provides a stable and clean power supply to the chip, provides a reset mechanism, configures the startup address, provides a clock reference, and provides a program burning channel**.
STM32 is a traditional MCU idea, with separate reset and start pins; the ESP32 module is more integrated, EN also serves as reset, and GPIO0 controls the download mode.
