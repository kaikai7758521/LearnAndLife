# Finds numbers in a two-dimensional array
## Question
> First there is a two-dimensional array. Each row increases from left to right, and each column increases from top to bottom. Write a function to find the target number in the array.

```Json
[
    [1, 2, 8, 9],
    [2, 4, 9, 12],
    [4, 7, 10, 13],
    [6, 8, 11, 15]
]
```
### Ideas
You can use its incremental scheme to first determine the area where the number is located, and then gradually narrow the range until you find the final result.

```Swift
func findTargNumInMatrix(_ matrix:[[Int]], _ target: Int) -> Bool {
    var found = false
    
    var row = 0, col = matrix[0].count - 1
    while row < matrix[0].count && col > 0 {
        if matrix[row][col] == target {
            found = true
            break
        } else if matrix[row][col] > target {
            col -= 1
        } else {
            row += 1
        }
    }
    
    return found
}
```
