# Repeated numbers in  Array
## Question 1
There is an array of length n. All the numbers in the array are between 0 and n-1. Some of the numbers are repeated. Find any repeated number.

## Solution
Violent solution: Use a 2-layer for loop to find it directly without opening up a new space in the original space.

Use Set assistance: a for loop, each time the element is put into the set, until it is determined that the current element has been repeated in the set

Modify array implementation: try to put each element in its correct position
```Swift
func findDuplicateNumber(_ nums:[Int]) -> Int {
    var newNums: [Int] = nums // 由于swift不支持修改参数，所以必须复制一个
    for i in 0...newNums.count-1 {
        while newNums[i] != i {
            if newNums[i] == newNums[newNums[i]] {
                return newNums[i]
            } else {
                var temp = newNums[i]
                newNums[i] = newNums[temp]
                newNums[temp] = temp
            }
        }
    }
    return -1
}
```


## Question 2
There is an array with a length of n+1. All the numbers in the array are between 1 and n. Some of the numbers are repeated. Find any one (requires modifying the array)
Here refer to the dichotomy method to find
The idea is: split the array according to the length. If the number length of a certain fragment is greater than the number of the fragment itself, then there is duplication. We perform multiple binary searches on this fragment until the fragment is divided into 1. At this time, if the length of the divided array is still greater than 1, then all the fragments will be repeated numbers, and the first one in the range will be enough.
```Swift
func findDuplicateNumberAndNotModify(_ nums:[Int], _ length:Int) -> Int {
    if nums.count <= 0 {
        return -1
    }
    
    var start = 1
    var end = length - 1
    while end >= start {
        var middle = (end - start) / 2 + start
        var countRange = countRange(nums, length, start, middle)
        if end == start {
            if countRange > 1 {
                return start
            } else {
                break
            }
        }
        if countRange > middle - start + 1 {
            end = middle
        } else {
            start = middle + 1
        }
    }
    
    func countRange(_ nums:[Int], _ length:Int, _ start: Int, _ end: Int) -> Int {
        var countRange = 0
        if nums.count <= 0 {
            return 0
        }
        for i in 0...length-1 {
            if nums[i] >= start && nums[i] <= end {
                countRange += 1
            }
        }
        return countRange
    }
    
    return -1
}
```
