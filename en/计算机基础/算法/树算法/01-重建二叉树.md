# Reconstructs the binary tree
## Question, given the pre-order traversal and in-order traversal arrays of a binary tree, reconstruct the binary tree based on these two arrays

Problem-solving ideas:
First, analyze the characteristics of pre-order traversal and in-order traversal:
1. Preorder traversal of binary tree: the first node always follows the node, followed by the left subtree and the right subtree
2. In-order traversal of binary tree: left subtree first, then node, and finally right subtree

According to the above ideas, the characteristics of both can be used for recovery operations:
Obtain the following nodes from the pre-order traversal, and then determine the range of the left subtree and right subtree based on the in-order traversal, and continue to repeat this operation until the left subtree and right subtree are both empty.

## Solution
```Swift
func constructTree(_ preorder: [Int], _ inorder: [Int]) -> TreeNode? {
    if preorder.count == 0 || inorder.count == 0 {
        return nil
    }
    if preorder.count != inorder.count {
        return nil
    }
    
    var root = TreeNode(preorder[0])
    
    for i in 0...inorder.count-1 {
        if inorder[i] == root.value {
            // 找到左子树的前序和中序，进行递归
            let preorderLeft: [Int] =  {
                if i >= 1 {
                    return Array(preorder[1...i])
                } else {
                    return []
                }
            }()
            let inorderLeft: [Int] = Array(inorder[0..<i])
            root.left = constructTree(preorderLeft, inorderLeft)
            
            let preorderRight: [Int] = Array(preorder[(i+1)...])
            let inorderRight: [Int] = Array(inorder[(i+1)...])
            root.right = constructTree(preorderRight, inorderRight)
        }
        
    }
    
    return root
}
```
