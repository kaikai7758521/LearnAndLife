# 日常饮食与营养基础
> 一句话：日常饮食先保证**总量合适、蛋白质足够、蔬菜水果充足、少加工食品**，不必追逐某种「超级食物」或极端饮食法。
> 说明：以下为一般性营养科普，不构成医疗建议；孕期、哺乳期、慢性病、进食障碍或特殊用药人群，请咨询医生或注册营养师。

## 一、能量平衡：体重变化的底层逻辑
```
体重变化 ≈ 摄入热量 - 消耗热量
消耗 = 基础代谢 BMR + 活动消耗 + 食物热效应
```
- 基础代谢占大头，肌肉量、体重、年龄、性别都会影响；
- 活动消耗包括走路、运动、NEAT（非运动性活动）；
- 减重需要**长期小幅热量缺口**，增重需要小幅盈余；
- 估算公式只能参考，真实值要用 2~4 周的体重趋势校准。

经验值：
- 每日 300~500 kcal 缺口，大约每周减 0.3~0.5 kg；
- 缺口过大容易掉肌肉、疲劳、反弹；
- 体重每天波动 0.5~2 kg 很正常（水分、盐分、糖原、排便）。

## 二、三大营养素与膳食纤维
| 营养素 | 作用 | 一般建议 |
|---|---|---|
| 蛋白质 | 肌肉、免疫、酶、饱腹 | 普通成人 0.8~1.0 g/kg；规律运动 1.2~1.6 g/kg |
| 碳水化合物 | 主要能量来源、脑与肌肉 | 依活动量 3~7 g/kg；耐力运动可更高 |
| 脂肪 | 激素、细胞膜、脂溶性维生素 | 占总能量 20%~35%，少反式脂肪 |
| 膳食纤维 | 肠道、血糖、饱腹 | 25~30 g/天 |
| 水 | 体温、代谢、循环 | 约 1.5~2 L/天，按出汗调整 |

> 蛋白质不是「越多越好」：肾功能异常者需遵医嘱；普通健康人按体重与活动量分配即可。

### 蛋白质来源
- 动物：鸡蛋、奶、鱼、虾、鸡胸、瘦牛肉、瘦肉；
- 植物：大豆及豆制品、鹰嘴豆、扁豆、坚果、全谷物；
- 植物蛋白互补：豆类 + 谷物（如米饭 + 豆腐）即可覆盖必需氨基酸。

## 三、餐盘法：不用称重的简单框架
```
½ 盘蔬菜水果
¼ 盘优质蛋白
¼ 盘主食（优先全谷物/薯类）
+ 少量健康脂肪（坚果、橄榄油、牛油果）
```
- 蔬菜每天 300~500 g，深色蔬菜占一半；
- 水果每天 200~350 g，优先整果而不是果汁；
- 主食一半换成糙米、燕麦、全麦、玉米、红薯；
- 蛋白质每餐有一个手掌大小的量；
- 烹饪少油少盐，多用蒸、煮、炖、烤。

## 四、怎么选食物
### 1. 优先
- 天然、少加工：蔬菜、水果、全谷物、豆类、蛋奶、鱼肉、瘦肉；
- 配料表短的食品；
- 高纤维、低添加糖、低钠。

### 2. 控制
- 含糖饮料、奶茶、果汁饮料；
- 油炸食品、酥皮点心、加工肉制品；
- 高盐零食、酱料、方便面；
- 酒精（没有「健康饮酒量」，越少越好）。

### 3. 看标签
| 看什么 | 注意 |
|---|---|
| 每 100 g / 每份 | 先确认单位，别被「每份」误导 |
| 配料表 | 排在前面的含量高 |
| 添加糖 | 白砂糖、果葡糖浆、麦芽糖浆都算 |
| 钠 | 每 100 g 超过 600 mg 算偏高 |
| 纤维 | 全谷物/豆类通常更高 |
| 反式脂肪 | 配料表有「氢化植物油」要警惕 |

## 五、三餐与加餐
### 1. 三餐
- 早餐：蛋白质 + 主食 + 水果，例如鸡蛋 + 燕麦 + 牛奶 + 香蕉；
- 午餐：一拳主食 + 一掌蛋白 + 两拳蔬菜；
- 晚餐：清淡、少油，睡前 2~3 小时吃完即可；
- 不必严格「几点后不能吃」，总量与结构更重要。

### 2. 加餐
- 饿的时候优先：酸奶、坚果、水果、水煮蛋、豆浆；
- 坚果一小把（约 20~30 g），不要边看剧边吃一整袋；
- 训练前后可加一份碳水 + 蛋白质。

### 3. 外食技巧
- 先点蔬菜和蛋白质，再点主食；
- 酱料分开装，少喝汤底；
- 优先蒸、煮、烤，少选油炸、糖醋、干锅；
- 饮料选白水/无糖茶。

## 六、水与饮料
- 白水是最好的日常饮料；
- 咖啡/茶适量可以，注意加糖和奶精；
- 含糖饮料是「液体热量」，饱腹感差，容易超量；
- 运动超过 60~90 分钟或大量出汗，再考虑电解质饮料；
- 酒精影响睡眠、恢复与判断力，能不喝就不喝。

## 七、不同目标怎么调整
| 目标 | 做法 |
|---|---|
| 减脂 | 小幅热量缺口 + 足够蛋白 + 力量训练 + 走路 |
| 增肌 | 小幅热量盈余 + 蛋白 1.6 g/kg 左右 + 渐进超负荷 |
| 维持 | 规律三餐、蛋白质均匀分配、每周称重看趋势 |
| 素食 | 豆类/豆制品 + 全谷物 + 坚果，注意铁、B12、钙、Omega-3 |
| 乳糖不耐 | 无乳糖奶、酸奶、奶酪，或豆制品补钙 |

> 不建议长期极低碳水、极低脂肪或单一食物饮食；可持续性比短期掉秤更重要。

## 八、一周简单采购与菜单
### 采购清单
- 蛋白：鸡蛋、鸡胸/鸡腿、鱼、虾、豆腐、牛奶/酸奶、豆类；
- 主食：大米、燕麦、全麦面包、红薯、玉米、意面；
- 蔬菜：绿叶菜、番茄、胡萝卜、西兰花、菌菇；
- 水果：苹果、香蕉、橙子、蓝莓等当季水果；
- 脂肪：橄榄油、坚果、牛油果；
- 调味：葱姜蒜、酱油、醋、黑胡椒、香料。

### 一日示例
| 餐 | 示例 |
|---|---|
| 早餐 | 燕麦 + 牛奶 + 鸡蛋 + 香蕉 |
| 午餐 | 糙米饭 + 香煎鸡胸 + 西兰花 + 番茄 |
| 加餐 | 无糖酸奶 + 一小把坚果 |
| 晚餐 | 红薯 + 清蒸鱼 + 炒青菜 + 豆腐汤 |

## 九、常见误区
1. ❌ 碳水让人发胖：总热量过剩才是主因，碳水是重要能量来源；
2. ❌ 脂肪都不健康：坚果、鱼、橄榄油是必需脂肪酸来源；
3. ❌ 不吃晚饭瘦得快：长期总摄入与可持续性更重要；
4. ❌ 「排毒」产品能清肠：肝肾本身就是解毒器官，不需要额外排毒；
5. ❌ 超级食物能治病：没有单一食物能替代均衡饮食；
6. ❌ 果汁等于水果：果汁少了纤维，糖吸收更快；
7. ❌ 标签「无糖」就随便吃：可能含代糖/淀粉/脂肪，仍有热量；
8. ❌ 蛋白质只能靠肉：豆类、奶、蛋、谷物组合同样可以；
9. ❌ 体重每天涨了就是胖了：水分与糖原波动很大，看 2~4 周趋势；
10. ❌ 健康饮食必须昂贵：鸡蛋、豆制品、当季蔬菜、主食都很便宜。

## 十、总结
- 先看**总量与结构**，再看细节；
- 每餐有蛋白质、有蔬菜、有主食，基本不会差太多；
- 少加工、少含糖饮料、少酒精，多天然食物；
- 能长期坚持的饮食，才是好饮食。
