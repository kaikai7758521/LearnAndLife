# 钓鱼入门
> 一句话：钓鱼是「找鱼 + 让鱼咬钩 + 把鱼稳稳拿上来」的系统工程。新手先别急着买贵装备，把**合规、安全、基本钓组和选点**搞明白，鱼获自然会多起来。
> 说明：各地对钓具、鱼种、尺寸、禁渔期规定不同，出发前先查当地渔业部门/钓场规则。

## 一、先确认：合规与安全
### 1. 合规
- 是否需要**垂钓许可/钓证**；
- 是否处于**禁渔期/禁渔区**；
- 哪些鱼种有**最小尺寸、每日限额**；
- 是否允许夜钓、船钓、多竿；
- 保护区、饮用水源地、私人水域通常禁止垂钓。

### 2. 安全清单
| 风险 | 做法 |
|---|---|
| 高压线 | 碳素竿导电，远离电线，雷雨天收竿 |
| 落水 | 岸边湿滑、涨潮、船钓穿救生衣 |
| 鱼钩 | 戴眼镜/帽子，备剪线钳，倒刺钩小心摘 |
| 中暑/失温 | 防晒、补水，天冷分层穿衣 |
| 蚊虫/蜱虫 | 长袖长裤、驱虫剂，回家检查 |
| 独自出行 | 告诉家人位置与返回时间，带手机/充电宝 |
| 鱼鳍/鳃 | 戴手套，避免被划伤感染 |

> 不要为了捡漂、追竿下水；不要在大坝泄洪区、礁石浪区、雷雨天气停留。

## 二、装备：先买「够用」，再升级
### 1. 最小清单
| 类别 | 内容 | 新手建议 |
|---|---|---|
| 竿 | 手竿或直柄路亚竿 | 3.6~4.5m 手竿，或 1.8~2.1m 直柄路亚竿 |
| 轮 | 纺车轮 | 2000~3000 型，泄力顺滑 |
| 线 | 尼龙/PE/碳线 | 手竿 1.0~2.0 号尼龙；路亚 PE 0.8~1.2 号 + 碳前导 |
| 钩 | 袖钩/伊势尼/路亚钩 | 按目标鱼选大小，宁可小一号 |
| 漂 | 立漂/七星漂 | 吃铅 1~2g 入门 |
| 铅 | 铅皮/咬铅 | 注意部分地区禁铅 |
| 配件 | 八字环、连接环、太空豆 | 小配件别省 |
| 工具 | 摘钩钳、剪线钳、抄网、毛巾 | 抄网能显著减少跑鱼 |
| 饵 | 蚯蚓/玉米/商品饵/路亚假饵 | 先问当地钓友用什么 |

### 2. 预算思路
- 第一套控制在可接受范围，优先「竿不软、轮不卡、线不假」；
- 线和钩是最便宜的耗材，也是跑鱼的高发点，定期换；
- 不要盲目追求「一根竿打天下」：手竿、路亚、海钓是不同玩法。

## 三、常见钓法与钓组
### 1. 手竿台钓/悬坠钓
```
竿稍 → 主线 → 太空豆 → 漂座 → 铅皮座 → 八字环 → 子线 → 双钩
```
- 通过调整铅皮让浮漂露出目标目数；
- 钓底、钓浮、钓离底，靠「找底」和「调漂」控制；
- 适合鲫鱼、鲤鱼、罗非等淡水鱼。

### 2. 路亚
- 用假饵模仿小鱼/昆虫，靠收线手法诱发攻击；
- 常见饵：亮片、米诺、软虫、VIB、雷蛙；
- 目标鱼：鲈鱼、翘嘴、黑鱼、马口等；
- 关键是「找结构 + 控泳层 + 变速收线」，不是一直猛收。

### 3. 海钓/矶钓
- 受潮汐、浪况、礁石影响大，安全要求最高；
- 常用浮游矶钓、沉底钓、铁板；
- 必须关注潮汐表、风浪预报、当地禁钓区。

### 4. 冰钓
- 只在确认冰层厚度安全的区域进行；
- 需要冰钻、冰钓竿、保温装备；
- 不建议新手独自冰钓。

## 四、选点：鱼在哪里
### 1. 找结构
- 水草边缘、芦苇缝、倒树、桥墩、乱石区；
- 深浅交界、入水口、回水湾、下风口；
- 夏天找阴凉/深水，冬天找向阳/深水；
- 雨天入水口溶氧高，常有鱼聚集。

### 2. 看天气
| 条件 | 一般规律 |
|---|---|
| 清晨/傍晚 | 鱼活性高，窗口期 |
| 阴天/小雨 | 光线弱，鱼敢靠边 |
| 气压骤降/闷热 | 鱼口可能变差 |
| 冷空气过境后 | 短时间难钓，等稳定 |
| 大风 | 下风口食物聚集，但抛投困难 |

> 天气规律只是参考，同一个水域不同钓位差异可能更大；多观察、多换点。

## 五、绑钩与基本操作
### 1. 两个够用的结
- **改进型克林奇结**：穿钩眼 → 绕线 5~7 圈 → 线头穿回靠近钩眼的小环 → 润湿 → 拉紧；
- **帕洛玛结**：对折线穿钩眼 → 打一个松结 → 把钩子从环中穿过 → 润湿拉紧。
> 拉紧前一定**沾水**，避免摩擦伤线；拉完后拉一下钩子确认不滑。

### 2. 抛竿与刺鱼
- 手竿：轻抛到位，别甩鞭；风大时降低抛投幅度；
- 路亚：利用竿稍弹力，落水前用拇指控线杯；
- 看到顿口/黑漂，**手腕短促发力**刺鱼，不要大幅抡竿；
- 中鱼后保持竿身弯曲，用泄力/遛鱼消耗体力，别硬拉。

### 3. 抄鱼
- 鱼翻白后再抄，抄网入水后从鱼头方向迎上去；
- 不要用竿直接提鱼上岸，容易断竿/脱钩。

## 六、鱼获处理与放流
- 留鱼：按当地限额，尽快放血/保鲜，避免暴晒；
- 放流：湿手操作、不要捏鱼鳃、不要长时间离水；
- 摘钩困难时剪线，别硬拽；
- 把鱼放回水中后扶正，等它有力气再松手；
- 外来入侵鱼种按当地规定处理，不要随意放生。

## 七、新手常见问题
| 问题 | 原因 | 处理 |
|---|---|---|
| 抛投炸线 | 线杯刹车太小、饵太轻 | 调大刹车，顺风练抛 |
| 线打卷 | 线太旧、卷线器收线太松 | 换线、重新上线 |
| 浮漂不走 | 钓组没到底/水深不对 | 重新找底、调漂 |
| 有口不中 | 钩太大、饵太硬、提竿太早/太晚 | 换小钩、软饵、放口 |
| 中鱼跑鱼 | 钩不锋利、线有伤、泄力太紧 | 换钩换线、调松泄力 |
| 一直没口 | 钓位/泳层/饵不对 | 换点、换深度、换饵 |
| 挂底 | 结构区收线太慢 | 抬高竿稍、换饵、弃钩保线 |

## 八、最小入门方案
1. 先查当地规则，确认可以钓；
2. 买一套 3.6~4.5m 手竿 + 线组 + 漂 + 钩 + 抄网；
3. 找附近允许垂钓的公园湖/收费钓场，先练调漂和抛竿；
4. 目标鱼从鲫鱼/罗非开始，饵用蚯蚓或当地常用饵；
5. 每次记录：天气、钓位、水深、饵、鱼口，积累自己的经验。

## 九、常见误区
1. ❌ 装备越贵鱼越多：钓位、天气、饵料状态比竿的价格更重要；
2. ❌ 钩越大越不容易跑鱼：目标鱼小、钩大反而挡口；
3. ❌ 没口就死等：主动换点、换泳层、换饵；
4. ❌ 有口就大力扬竿：容易拉豁鱼嘴、断线；
5. ❌ 放流就是扔回水里：操作不当会大幅降低存活率；
6. ❌ 哪里都能钓：禁渔区、保护区、私人水域可能违法；
7. ❌ 雷雨天「鱼口好」：碳素竿+水边是极高风险组合，立即收竿。

## 十、总结
- 钓鱼 = **合规 + 安全 + 找鱼 + 钓组 + 操作**；
- 新手先练「调漂、抛竿、刺鱼、抄鱼」四个基本动作；
- 多记录、多观察，比盲目买装备进步快；
- 带走垃圾、遵守限额、善待鱼获，才能一直有鱼可钓。
