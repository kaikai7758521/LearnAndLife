# 篮球

NBA直播常见词

- **REB** = Rebounds → **篮板**（总篮板，进攻篮板 OREB + 防守篮板 DREB）
- **AST** = Assists → **助攻**（传球直接促成队友得分）
- **STL** = Steals → **抢断**
- **BLK** = Blocks → **盖帽 / 封盖**
- **TO** = Turnovers → **失误**（很多地方也写 TOV）
- **PF** = Personal Fouls → **个人犯规**（NBA 球员累计 6 次犯满离场）
- **PTS（Points）**：**得分**，球员本场一共拿到多少分statsdmz.n...
- **FG（Field Goals）**：**运动战投篮**（两分 + 三分都算，一般格式：命中 - 出手，例如 7-14，7 中 14）；**FG%** 就是投篮命中率
- **3P（Three-Pointers）**：**三分球**，同样是 命中 - 出手；**3P%** 三分命中率
- **FT（Free Throws）**：**罚球**，命中 - 出手；**FT%** 罚球命中率
- **+/-（Plus-Minus，正负值）**：球员在场上这段时间里，球队净胜对手多少分。
