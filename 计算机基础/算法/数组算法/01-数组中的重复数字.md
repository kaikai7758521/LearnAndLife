# 数组中重复的数字
> 题目来源：剑指 Offer 03。两问共享同一个核心：**值域有限**——要么让「值」回到「下标」，要么在「值域」上做二分，要么把数组看成一张有向图找环。
> 约定：返回任意一个重复数字；若不存在返回 `-1`。

## 一、两问的差异
### 题目一
长度 `n` 的数组，所有元素都在 `0..<n`，至少有一个数字重复，找出**任意一个**。

- 值域与下标一一对应：数字 `i` 的「正确位置」就是下标 `i`；
- 因此可以用**下标归位**，把每个数换到它该在的位置；
- 允许修改数组时（例如 `inout`），时间 `O(n)`、额外空间 `O(1)`；
- Swift 数组是值类型：`var a = nums` 再交换不会改调用方，但触发 COW 复制后空间是 `O(n)`。

### 题目二
长度 `n+1` 的数组，所有元素都在 `1...n`，至少有一个数字重复，找出任意一个，**要求不修改数组**。

- 值域比下标少一个，根据抽屉原理必然重复；
- 不能排序、不能交换，只能在**值域**上二分，或用 **Floyd 判圈**；
- 这是很多人容易看错的地方：题目二的关键限制是「不修改」，而不是「必须修改」。

## 二、解法总览
| 解法 | 时间 | 空间 | 修改原数组 | 适用 |
|---|---|---|---|---|
| 暴力双重循环 | O(n²) | O(1) | 否 | 入门/数据量小 |
| 哈希 Set | O(n) | O(n) | 否 | 通用，最直观 |
| 排序后相邻比较 | O(n log n) | O(1)~O(n) | 是（或副本） | 允许排序时 |
| 下标归位 | O(n) | O(1)（inout）/ O(n)（副本） | 是（或副本） | 题目一 |
| 值域二分 | O(n log n) | O(1) | 否 | 题目二 |
| Floyd 判圈 | O(n) | O(1) | 否 | 题目二，最优 |

> 面试时先问清楚：**能不能修改输入？有没有空间限制？返回任意一个还是第一个？** 不同答案对应不同解法。

## 三、题目一：下标归位
### 思路
遍历数组，把 `nums[i]` 换到下标 `nums[i]` 的位置：
- 如果 `nums[i] == i`，已经归位，继续；
- 如果 `nums[i]` 位置上已经是同一个值，说明找到重复；
- 否则交换，继续处理当前位置。

### Swift 实现（不修改入参的版本）
```swift
func findDuplicate(_ nums: [Int]) -> Int {
    guard !nums.isEmpty else { return -1 }
    var a = nums                       // 值语义 + COW：不改调用方，但会复制，空间 O(n)
    for i in a.indices {
        while a[i] != i {
            let target = a[i]
            if a[target] == a[i] {     // 目标位置已经是同一个值
                return a[i]
            }
            a.swapAt(i, target)
        }
    }
    return -1
}
```
如果允许直接修改入参，用 `inout` 可以做到真正的 `O(1)` 额外空间：
```swift
func findDuplicateInPlace(_ nums: inout [Int]) -> Int {
    for i in nums.indices {
        while nums[i] != i {
            let target = nums[i]
            if nums[target] == nums[i] {
                return nums[i]
            }
            nums.swapAt(i, target)
        }
    }
    return -1
}
```
### 正确性
- 每次交换至少让一个数字回到正确位置，最多交换 `n` 次；
- 若存在重复，必然在某个时刻出现「目标位置已是相同值」；
- 若遍历结束仍未发现，说明没有重复。

### 复杂度
- 时间 `O(n)`：每个元素最多被交换一次；
- 空间：不修改入参的版本是 `O(n)`（COW 复制）；`inout` 版本是 `O(1)`。

> 题目一如果要求「不修改数组」，下标归位就不适用，退回哈希 Set 或排序副本。

## 四、题目二：值域二分
### 思路
不要在下标上二分，要在**数字范围** `[1, n]` 上二分：
1. 取中点 `mid`，统计数组中落在 `[low, mid]` 的数字个数 `count`；
2. 如果 `count > mid - low + 1`，说明重复数字在左半区间；
3. 否则在右半区间；
4. 区间缩到只剩一个数，就是答案。

### Swift 实现
```swift
func findDuplicateBinarySearch(_ nums: [Int]) -> Int {
    guard nums.count >= 2 else { return -1 }

    var low = 1
    var high = nums.count - 1          // 值域上界 n
    while low < high {
        let mid = low + (high - low) / 2
        let count = nums.reduce(0) { partial, value in
            partial + ((value >= low && value <= mid) ? 1 : 0)
        }
        if count > mid - low + 1 {
            high = mid                 // 重复在左半
        } else {
            low = mid + 1              // 重复在右半
        }
    }
    return low
}
```
### 复杂度
- 时间 `O(n log n)`：二分 `log n` 轮，每轮扫一遍数组；
- 空间 `O(1)`，不修改数组。

### 易错点
- `high` 是**值域上界** `n = nums.count - 1`，不是下标上界；
- 统计范围是 `[low, mid]`，不是 `[0, mid]`；
- 题目保证有重复，所以循环结束 `low == high` 就是答案；若要处理无重复，需要额外校验。

## 五、题目二：Floyd 判圈（最优）
### 思路
把数组看成一个有向图：下标 `i` 指向 `nums[i]`。
- 因为值域是 `1...n`、长度是 `n+1`，从下标 0 出发一定会进入环；
- 环的入口就是重复的数字（有两个下标指向同一个值）。

### Swift 实现
```swift
func findDuplicateFloyd(_ nums: [Int]) -> Int {
    guard nums.count >= 2 else { return -1 }

    var slow = nums[0]
    var fast = nums[0]

    repeat {
        slow = nums[slow]              // 走一步
        fast = nums[nums[fast]]        // 走两步
    } while slow != fast

    slow = nums[0]                     // 一个指针回到起点
    while slow != fast {
        slow = nums[slow]
        fast = nums[fast]
    }
    return slow
}
```
### 复杂度
- 时间 `O(n)`；
- 空间 `O(1)`；
- 不修改数组，是题目二的最优解。

### 前提
- 数组长度 `n+1`、值域 `1...n`，保证 `nums[i]` 是合法下标；
- 如果值域包含 `0` 或可能越界，这个映射不成立，不能直接用。

## 六、其他解法
### 1. 哈希 Set
```swift
func findDuplicateSet(_ nums: [Int]) -> Int {
    var seen = Set<Int>()
    for value in nums {
        if !seen.insert(value).inserted {
            return value
        }
    }
    return -1
}
```
- 时间 `O(n)`，空间 `O(n)`；
- 最直观，适合不作为面试最优解、但工程里足够用的场景。

### 2. 排序
```swift
func findDuplicateSort(_ nums: [Int]) -> Int {
    let sorted = nums.sorted()
    guard sorted.count >= 2 else { return -1 }
    for i in 1..<sorted.count where sorted[i] == sorted[i - 1] {
        return sorted[i]
    }
    return -1
}
```
- 时间 `O(n log n)`，空间取决于是否允许原地排序；
- 会打乱原数组顺序，返回的也不一定是「第一个」重复值。

### 3. 暴力
```swift
func findDuplicateBruteForce(_ nums: [Int]) -> Int {
    for i in 0..<nums.count {
        for j in (i + 1)..<nums.count where nums[i] == nums[j] {
            return nums[i]
        }
    }
    return -1
}
```
- 时间 `O(n²)`，空间 `O(1)`；
- 只适合教学或极小数据量。

## 七、测试用例
```swift
func check(_ actual: Int, _ expected: Set<Int>) {
    assert(expected.contains(actual), "got \(actual), expected one of \(expected)")
}

// 题目一：0..<n
check(findDuplicate([2, 3, 1, 0, 2, 5, 3]), [2, 3])
check(findDuplicate([1, 1]), [1])
check(findDuplicate([0, 0, 1]), [0])

// 题目二：1...n，长度 n+1
check(findDuplicateBinarySearch([2, 3, 5, 4, 3, 2, 6, 7]), [2, 3])
check(findDuplicateFloyd([2, 3, 5, 4, 3, 2, 6, 7]), [2, 3])
check(findDuplicateFloyd([1, 1]), [1])
check(findDuplicateFloyd([3, 3, 3, 3]), [3])
```
建议覆盖：
- 空数组 / 只有一个元素；
- 重复值在开头、结尾、中间；
- 多个重复值（返回值只需属于集合）；
- 全部元素相同；
- 题目二的最大值 `n` 出现在边界。

## 八、常见坑
1. ❌ `for i in 0...nums.count-1`：空数组会因 `0...-1` 崩溃，用 `indices` 或先判空；
2. ❌ 递归/交换时下标越界：题目一必须保证值域在 `0..<n`，题目二在 `1...n`；
3. ❌ 在题目二里排序或交换：违反「不修改数组」的限制；
4. ❌ 值域二分写成下标二分：统计的是「数字落在区间内的个数」，不是「下标区间」；
5. ❌ Floyd 直接套用到题目一：题目一值域含 `0`，若 `nums[0] == 0`，从下标 0 出发会陷入自环并返回 0；Floyd 只适合题目二这种 `1...n` 且长度 `n+1` 的约束；
6. ❌ 认为返回值必须是「第一个重复出现的数」：题目只要求任意一个，测试不要写死顺序。

## 九、总结
- 题目一的关键是**下标归位**：值域与下标重合，交换即可；
- 题目二的关键是**不修改**：要么在值域上二分，要么用 Floyd 判圈；
- 工程里优先可读性（Set/排序），面试里再根据限制选择最优解；
- 先确认约束，再写代码，比背题解更重要。
