# 查找二维数组中的数字
## 题目
> 先有一个二维数组，每一行都是从左至右递增，每一列都是从上到下递增，写一个函数在数组中寻找目标数

```Json
[
    [1, 2, 8, 9],
    [2, 4, 9, 12],
    [4, 7, 10, 13],
    [6, 8, 11, 15]
]
```
### 思路
可以利用其递增的方案，先判断出数字所在的区域，再逐步缩小范围，直到找到最后的结果

```Swift
func findTargNumInMatrix(_ matrix:[[Int]], _ target: Int) -> Bool {
    var found = false
    
    var row = 0, col = matrix[0].count - 1
    while row < matrix[0].count && col > 0 {
        if matrix[row][col] == target {
            found = true
            break
        } else if matrix[row][col] > target {
            col -= 1
        } else {
            row += 1
        }
    }
    
    return found
}
```
