# 二分查找
## 题目
给一个数组，这个数组是一个旋转数组，即最开始的若干个数子被放到数组的尾部，需要找到当前数组的最小值

## 解法 
这是一个典型的二分查找题目：
我们通过二分查找，找到反转的切片，然后在当前切片内再进行二分，直到找到最小值

```Swift
func findMinNumberInNums(_ nums: [Int]) -> Int {
    var pre = 0, after = nums.count - 1
    var mid = pre
    
    // [5, 1, 2, 3, 4, 4]
    while nums[pre] >= nums[after] {
        if (after - pre) == 1 {
            mid = after
            break
        }
        mid = (after - pre) / 2 + pre
        
        if nums[pre] == nums[after] && nums[mid] == nums[pre]{
            var min = nums[0]
            for i in nums {
                if min >= i {
                    min = i
                }
                return min
            }
        }
        
        if nums[mid] <= nums[pre] {
            after = mid
        } else if nums[mid] >= nums[pre] {
            pre = mid
        }
        
    }
    
    return nums[mid]
    }
```
