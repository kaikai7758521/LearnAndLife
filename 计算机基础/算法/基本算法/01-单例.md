# 单例
## iOS的单例
iOS中单例的构造方法相对简单，oc可以使用`dispatch_once`实现，而 swift中移除了`dispatch_once`，只需使用`static关键字的方式实现即可`
```Objective-c
+ (instancetype)sharedInstance {
    static Demo instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[self alloc] init];
    });
    return instance;
}
```
Swift的直接使用即可
```Swift
class Manager {
    // 全局访问点
    static let shared = Manager()
    
    // 私有初始化器，防止外部 new / init
    private init() {}
}
```
## Java的单例
Java的单例虽然可以指定static，但是不同于iOS（iOS的static同C、C++），iOS中会Runtime的方式自动初始化static，方便后续进行初始化，内部自动保证初始化一次，所以不存在多线程风险，但是Java的类加载特性不保护静态变量的null判断
### 初始化则加载（线程安全）
```Java
public class Manager {
    // 类加载阶段就初始化，JVM 类加载的 <clinit> 是同步的
    private static final Manager INSTANCE = new Manager();
    private Manager(){}
    public static Manager getInstance(){
        return INSTANCE;
    }
}

```
### 懒加载（需要时加载，有多线程风险，加锁进行双重判断）
```Java
// DCL
public static Manager getInstance() {
    if (instance == null) {
        synchronized (Manager.class) {
            if (instance == null) {
                instance = new Manager();
            }
        }
    }
    return instance;
}

```
