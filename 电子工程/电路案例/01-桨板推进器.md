# 桨板电动推进器电路设计笔记
> 适用场景：SUP桨板外挂电动推进器，支持无线遥控、无级调速、前进/后退、转向；区分不同电池方案做电路规划，重点标注安全与实操注意事项。
> ⚠️ 重要声明：本设计仅作学习参考，水上电气设备存在进水、短路、起火风险，成品务必做好防水与安全冗余。

## 一、功能需求梳理
1. 无线遥控：遥控器 ↔ 接收模块通信
2. 电机控制：前进、倒退、无级调速（PWM）
3. 转向控制：舵机驱动舵叶实现方向控制
4. 电源适配：支持 3S/4S 锂电池（航模锂电）、12V 铅酸/磷酸铁锂方案
5. 保护需求：过流、欠压、防反接、急停、防水隔离

> 核心架构：**电池 → 电源分配/保护单元 → 电调（驱动主推进电机）+ 舵机驱动单元 + 遥控接收模块**

## 二、整体电路
```
动力电池组
├─ 主保护支路：保险丝 → 防反接模块
├─ BEC降压模块：输出5V，给接收机、舵机供电
├─ 水下无刷电调ESC：接收PWM信号，驱动推进无刷电机（支持正反转）
└─ 防水舵机：接收PWM信号，控制转向舵叶

遥控器（发射机） ===2.4G无线===> 接收机
接收机通道分配：
- CH1：油门通道（速度控制，中位停机，上推前进，下拉后退）
- CH2：转向通道（左右方向控制）
```

> 说明：优先选用**支持正反转的水下无刷电调**；普通航模电调默认不支持倒车，不要混用。

## 三、分模块电路详解
### 3.1 无线遥控模块
推荐方案：2.4G航模遥控器（富斯FS-i6、乐迪AT9S等）
- 发射端：摇杆，一路油门、一路转向
- 接收端：接收机输出标准航模PWM信号（50Hz，1000~2000us脉宽）
- 供电：接收机工作电压4.8~6V，由BEC供电，**禁止直接接锂电高压**
- 接线：
  - 油门通道 → 电调信号线（白=信号，红=5V，黑=GND）
  - 转向通道 → 舵机信号线

> ⚠️ 电调自带BEC和外置BEC二选一，**不要同时给接收机双路供电，会烧毁接收机**。

### 3.2 推进电机驱动单元（ESC电调）
选用：**水下无刷电调，支持正反转，防水款**
- 输入：动力电池电压
- 输出：三相线接无刷电机
- 信号口：PWM输入
- 内置功能：油门曲线设置、正反转切换、刹车设置、低压保护LVC
> 接线要点：
> 1. 电调粗红、粗黑接电池主电源；三相粗线接电机（调换任意两根相线，电机转向反转）
> 2. 信号线三针：GND、信号、5V；如果使用外置BEC供电接收机，需要把电调信号线里的红线剪断（切断电调内置BEC输出）

### 3.3 转向舵机单元
- 选型：大扭矩防水舵机（水下专用，普通塑料舵机进水直接损坏），扭矩建议 ≥15kg·cm
- 供电：5~6V，和接收机共用BEC电源
- 控制：PWM信号，脉宽1000μs左舵，1500μs中位，2000μs右舵
- 机械：舵臂连杆连接水下舵叶，预留机械限位，防止堵转烧舵机

### 3.4 电源与BEC降压单元（重点，分电池方案）
> BEC作用：把动力电池高压降到5V，给接收机、舵机供电

#### 方案A：3S锂电（11.1V，充满12.6V）
- 电池：3S 航模锂电池，容量 5Ah~20Ah，适合中小型桨板
- 主回路：20A~40A保险丝（根据电机功率）+ 大功率防反接MOS模块
- BEC选型：DC-DC降压模块，输入7~18V，输出5V 3A以上（舵机启动冲击电流大）
- 低压保护：电调LVC设置 9.0V 截止（单芯3.0V），防止过放鼓包

#### 方案B：4S锂电（14.8V，充满16.8V）
- 电池：4S锂电，动力更强，速度更高
- 主回路：30A~60A保险丝
- BEC选型：DC-DC降压模块，输入10~24V，输出5V 3A+，宽压版本
- 低压保护：LVC设置 12.0V 截止（单芯3.0V）
> 注意：4S电压高，绝缘要求更高，漏电风险更大

#### 方案C：12V铅酸 / 12V磷酸铁锂（4串铁锂充满14.6V）
- 电池：12V铅酸/磷酸铁锂，成本低、安全性好，缺点是体积重量偏大
- 主回路：同3S方案，保险丝按电机额定电流匹配
- BEC：输入9~18V，输出5V
- 低压阈值：铅酸建议低于11V停机；磷酸铁锂单串2.5V保护

### 3.5 保护电路清单（必加）
1. **防反接**：大功率防反接MOS模块，不建议只用二极管（大电流发热严重）
2. **主保险丝**：紧贴电池正极出线位置，短路第一时间熔断
3. **低压保护**：优先电调自带LVC；预算充足额外加独立低压报警器+继电器切断主回路
4. **急停开关**：防水船型急停，串联在主正极回路，落水一键断电
5. **共地**：所有模块GND必须连在一起，否则PWM信号异常、舵机乱抖、油门失控

## 四、完整接线总表
| 器件 | 电源正极 | 电源负极 | 信号线 | 备注 |
|---|---|---|---|---|
| 动力电池 | →保险丝→防反接→电调主正 | 电调主负 | - | 主功率回路 |
| 电调ESC | 主正 | 主负 | PWM信号 →接收机CH1 | 红线剪断（外置BEC时） |
| 舵机 | BEC 5V | BEC GND | PWM信号 →接收机CH2 | 防水舵机 |
| 接收机 | BEC 5V | BEC GND | - | 所有信号GND共地 |
| BEC降压 | 电池主正（保险丝后） | 电池主负 | - | 输出5V给舵机+接收机 |

## 五、电路调试步骤
1. 断电接线，全部GND共地，反复检查有没有正负极短路
2. 单独给接收机+BEC上电，遥控器对频，测试舵机左右转向是否顺滑、限位正常
3. 断开电机相线，上电校准电调油门行程（电调校准是必须步骤，否则油门不线性、无倒车）
4. 接上电机相线，低速测试前进/倒退，确认转向和摇杆方向一致；转向相反调换电机任意两根相线
5. 测试急停、低压报警，确认保护动作正常
6. 陆上全部调试完成，再下水测试

## 六、安全与实操注意事项
### 电气安全
1. 水上属于高湿导电环境，所有接线优先焊接+热缩管密封；接头选用防水航空插头，禁止普通杜邦线裸露泡水。
2. 锂电严禁挤压、穿刺；下水前检查电池外壳鼓包、破皮，锂电池建议放置在独立密闭防水电池仓。
3. 功率回路和信号回路分开走线，大电流主线远离信号线，减少电磁干扰，避免遥控失控。
4. 电调、BEC不能完全密封锁死，功率器件工作发热，优先选用可散热的灌封胶做防水，完全密闭无散热会过热烧毁。
5. 不要随意加大保险丝规格，保险丝是最后一道短路保护。
6. 遥控器务必开启失控保护：失控时油门归零，舵机回中，防止失控冲出去。

### 机械与防水
1. 普通舵机、普通航模电调**不防水**，水下使用必须购买专用水下款；普通航模器件泡水极易损坏、短路起火。
2. 推进电机、舵叶在水下，线缆出线位置使用格兰头密封防水，线缆弯折处预留余量，防止拉扯断线。
3. 桨板是柔性载体，航行震动大，所有接线做好抗震固定，避免接头震松虚接打火。

### 使用规范
1. 下水前陆上全功能预检：前进、后退、调速、转向、急停、遥控距离测试。
2. 不要满油门长时间持续工作，电机、电调会过热；高温季节降低持续功率。
3. 上岸后，及时用淡水冲洗推进器，充分晾干，检查接头有没有渗水腐蚀。
4. 严禁在河道主航道、船舶通行区域高速使用；全程穿戴救生衣。

### 电路避坑清单
- ❌ 错误：普通航模电调直接拿来做倒车；大部分只能正转，倒车容易炸管
- ❌ 错误：电调BEC和外置BEC同时给接收机供电
- ❌ 错误：信号线不共地，舵机抖动、油门抽风
- ❌ 错误：BEC电流余量太小，舵机打方向瞬间拉低电压，接收机重启失控
- ❌ 错误：不设置失控保护，遥控器丢信号后电机持续运转

## 七、可选升级拓展电路
1. 增加电压显示表头：防水电压表，实时查看电池电压
2. 增加声光报警：低压蜂鸣器，电压偏低提前提醒
3. 双路独立继电器：大功率机型，独立控制主电机电源
4. 带霍尔传感器的转速反馈，实现闭环恒速控制
