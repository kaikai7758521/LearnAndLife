# 电源电路基础：从 LDO 到 DC-DC
> 一句话：**电源设计就三件事：电压对、纹波小、发热可控**；选型先看压差、电流、噪声与效率，再谈外围器件和 PCB 布局。
> 定位：从最小系统的「3.3V 供电」往上走一层，讲清楚 LDO、Buck/Boost、去耦、保护与布局。MCU 最小系统本身见 `01-最小系统.md`。

## 一、先明确电源的约束
任何一路电源，先回答这些问题：

| 约束 | 典型问题 |
|---|---|
| 输入范围 | 12V？5V USB？单节锂电 3.0~4.2V？ |
| 输出电压/精度 | 3.3V ±2%？1.8V 核压？ |
| 最大/峰值电流 | 持续 500mA，峰值 2A？ |
| 纹波/噪声 | 数字负载 50mV 够，ADC/射频要 <10mV？ |
| 效率/发热 | 电池供电、密闭外壳？ |
| 瞬态响应 | 负载从 10mA 跳到 1A，电压跌落多少？ |
| 尺寸/成本/EMI | 小体积、低成本、过认证？ |

```
输入 → 保护（保险丝/TVS/防反接）→ 转换（LDO/DC-DC）→ 滤波/去耦 → 负载
                                      ↑
                                 使能/时序/反馈
```

## 二、LDO：最简单也最容易过热
### 1. 原理
LDO（Low Dropout Regulator）本质是一个**可调电阻**：通过调整管把多余的电压降掉，输出稳定电压。
```
Vout ≈ Vref × (1 + R1/R2)
```
### 2. 关键参数
| 参数 | 含义 | 注意 |
|---|---|---|
| Dropout | 维持稳压所需的最小压差 | 压差不够时输出会跟着输入掉 |
| 静态电流 Iq | 无负载时自身耗电 | 电池设备要选低 Iq |
| PSRR | 电源抑制比 | 随频率升高而下降 |
| 输出噪声 | 自身噪声 | ADC、射频、音频敏感 |
| 稳定性 | 对输出电容 ESR 的要求 | 不是电容越大越好，按手册选 |
| 瞬态响应 | 负载跳变时的恢复能力 | 与环路带宽、输出电容有关 |

### 3. 发热计算（最重要的公式）
```
Ploss = (Vin - Vout) × Iout + Vin × Iq
效率 ≈ Vout / Vin
```
例子：
- 12V → 3.3V / 0.5A：`(12-3.3)×0.5 = 4.35W`，SOT-23 直接烧毁，必须 DC-DC；
- 5V → 3.3V / 0.3A：`(5-3.3)×0.3 = 0.51W`，SOT-223 + 铺铜可接受；
- 3.6V → 3.3V / 0.2A：`0.06W`，LDO 非常合适。

### 4. 适用场景
✅ 压差小、电流小、对噪声敏感（模拟/射频/音频）、成本敏感；
❌ 大压差、大电流、电池供电（效率低）、需要升压。

> LDO 只能降压，不能升压；输入低于 `Vout + Dropout` 时输出会失去稳压。

## 三、DC-DC：用开关换效率
### 1. 三种基本拓扑
| 拓扑 | 关系（理想） | 场景 |
|---|---|---|
| Buck 降压 | `Vout = D × Vin` | 12V/5V → 3.3V/1.8V |
| Boost 升压 | `Vout = Vin / (1-D)` | 锂电 3.7V → 5V/12V |
| Buck-Boost | 可升可降 | 电池电压跨 3.3V 波动 |
| 反激/隔离 | 变压器耦合 | 需要隔离、多路输出 |

`D` 是占空比。实际还要考虑二极管/同步管压降、电感直流电阻、开关损耗。

### 2. 同步与非同步
- **非同步**：续流用肖特基二极管，简单、便宜，效率略低；
- **同步**：用 MOSFET 代替二极管，效率高，控制更复杂；
- 低压大电流场景优先同步 Buck。

### 3. 关键外围
| 器件 | 作用 | 选型要点 |
|---|---|---|
| 电感 L | 储能、平滑电流 | 饱和电流 > 峰值电流，DCR 小，屏蔽式 |
| 输入电容 | 吸收开关脉冲电流 | 低 ESR 陶瓷，靠近芯片 |
| 输出电容 | 平滑输出电压 | 容量 + ESR，满足纹波/瞬态 |
| 反馈电阻 | 设定输出电压 | 精度 1% 或更高，靠近 FB 脚 |
| 软启动/补偿 | 控制上电斜率与环路稳定 | 按手册计算，不要随意改 |

Buck 电感纹波电流：
```
ΔIL = (Vin - Vout) × D / (L × fsw)
```
一般取 `ΔIL` 为输出电流的 20%~40%。纹波太小电感大、瞬态差；太大则电容和 EMI 压力大。

输出纹波近似：
```
Vripple ≈ ΔIL / (8 × fsw × Cout) + ΔIL × ESR
```

### 4. 效率与损耗
- 导通损耗：`I² × Rds(on) × D`；
- 开关损耗：与 `fsw`、栅极电荷、电压摆幅相关；
- 电感铜损/磁损、电容 ESR 损耗；
- 轻载时进入 PFM/脉冲跳跃，效率高但纹波变大。

>  datasheet 的「峰值效率 95%」通常发生在特定电压/电流点；轻载和满载都要看曲线。

## 四、LDO vs DC-DC 怎么选
| 维度 | LDO | Buck DC-DC |
|---|---|---|
| 效率 | `Vout/Vin`，压差大时极低 | 85%~95% |
| 发热 | 大压差时严重 | 小 |
| 噪声/纹波 | 低 | 较高，需滤波 |
| 外围 | 少（输入/输出电容） | 电感、电容、反馈、补偿 |
| 成本/面积 | 低/小 | 较高/较大 |
| EMI | 无开关噪声 | 有，需要布局与屏蔽 |
| 升压 | ❌ | ✅（Boost） |

常见组合：**Buck 先降到接近目标电压，再用 LDO 后级净化**，兼顾效率与低噪声（如 12V→5V Buck→3.3V LDO 给模拟电路）。

## 五、去耦与滤波：别让噪声进芯片
### 1. 去耦电容
- **大容量（10µF/22µF）**：入口储能，缓冲负载突变；
- **小容量（0.1µF/1µF）**：靠近芯片电源脚，提供高频回流路径；
- 每个电源脚一个 0.1µF，尽量**短而粗**地接到电源脚与地；
- 过孔会引入电感，必要时多打几个过孔。

### 2. 电容不是越多越好
- 不同容值并联可能在某个频率形成**并联谐振**，阻抗反而升高；
- 关注电容的 ESL/ESR 与自谐振频率；
- LDO 对输出电容的 ESR 有稳定区间，盲目加大电容可能振荡。

### 3. 磁珠与滤波
- 磁珠（Ferrite Bead）在高频呈阻性，常用于数字/模拟电源隔离；
- 注意额定电流与直流电阻，压降不能影响负载；
- 磁珠 + 电容可能形成 LC 谐振，必要时加阻尼电阻；
- 射频/ADC 供电可用 LC 滤波或专用低噪声 LDO。

## 六、保护、时序与电池
### 1. 输入保护
| 保护 | 器件 | 作用 |
|---|---|---|
| 过流/短路 | 保险丝、PTC、eFuse | 限制电流，防止起火 |
| 过压 | TVS、OVP 芯片 | 吸收浪涌/静电 |
| 防反接 | P-MOS/理想二极管 | 防止电源接反烧板 |
| 浪涌/热插拔 | 软启动、热插拔控制器 | 限制上电冲击 |
| 过温 | OTP、温度开关 | 关闭或降额 |

### 2. 上电时序
- 多路电源（核压、IO、模拟）要按芯片要求顺序上电；
- 用 `EN`、`PG`（Power Good）串联，前一级稳定后再开下一级；
- 顺序错误可能导致闩锁、漏电、启动失败；
- 复位信号要在电源稳定后释放。

### 3. 电池与 USB
- 单节锂电：3.0~4.2V，需要过充/过放/过流保护；
- 充电芯片按 CC/CV 流程，注意充电电流与散热；
- USB 5V 供电要遵守枚举与电流协商；USB-C PD 需要协议芯片，**不能直接超额定电流取电**；
- 电池供电设备重点看轻载效率与静态电流。

## 七、PCB 布局：电源成败的一半
### 1. Buck 的「热环路」
```
输入电容 → 上管 → 下管 → GND → 输入电容
```
这个环路面积越小越好：
- 输入电容紧贴芯片 `VIN` 与 `GND`；
- 上管/下管/电感之间的走线短而宽；
- 开关节点（SW）铜面积适中：太大辐射 EMI，太小散热差；
- 电感下方避免敏感信号，必要时开槽或加屏蔽。

### 2. 反馈与采样
- FB 走线远离 SW 节点与电感，避免耦合噪声；
- 反馈电阻靠近 FB 脚，采样点尽量靠近负载（远端采样）；
- 高精度场景用 Kelvin 连接。

### 3. 地与散热
- 完整地平面，功率地与信号地单点/分区连接；
- 芯片底部散热焊盘打多个过孔到地平面；
- 按 `θJA` 与铜面积估算温升，别只看环境温度；
- 电感、MOSFET 是主要热源，远离温度敏感器件。

## 八、测量与调试
### 1. 纹波测量
- 用**探头地弹簧**，不要用长地线夹（会拾取开关噪声）；
- 示波器带宽限制 20MHz，AC 耦合；
- 在输出电容两端、负载端分别测；
- 记录满载/轻载/瞬态三种状态。

### 2. 常见波形问题
| 现象 | 可能原因 |
|---|---|
| 输出振荡 | 环路不稳定、输出电容 ESR 不匹配、补偿错误 |
| 上电过冲 | 软启动不足、反馈延迟、负载突变 |
| 纹波过大 | 电感太小、输出电容不足、布局差 |
| 轻载啸叫 | PFM 频率落入音频、电感/电容振动 |
| 发热严重 | 效率低、导通损耗、散热不足 |
| 启动失败 | 输入跌落、使能时序、限流触发 |

### 3. 效率与热测试
- 用电子负载扫电流，记录 `Vin×Iin` 与 `Vout×Iout`；
- 热像仪看热点，热电偶测关键器件；
- 长时间满载老化，观察温升与漂移。

## 九、选型流程与例子
### 1. 流程
1. 列出输入/输出/电流/噪声/效率/尺寸约束；
2. 估算 LDO 发热，超过 0.5~1W 优先考虑 DC-DC；
3. 选拓扑（Buck/Boost/Buck-Boost/隔离）；
4. 选芯片：开关频率、集成 MOS、静态电流、保护功能；
5. 算电感、输入/输出电容、反馈电阻；
6. 设计保护与时序；
7. 布局、打样、测纹波/效率/温升/EMI。

### 2. 例子
| 需求 | 推荐 |
|---|---|
| 12V → 5V / 2A | 同步 Buck |
| 5V → 3.3V / 200mA（模拟） | 低噪声 LDO |
| 3.7V 锂电 → 5V / 1A | Boost |
| 12V → 3.3V / 3A | 同步 Buck |
| 24V → ±12V（运放） | 反激/隔离或 Buck-Boost + 电荷泵 |
| 5V → 1.8V / 1A（FPGA 核） | 同步 Buck + 时序控制 |

## 十、常见误区
1. ❌ LDO 简单所以随便用：大压差下发热会直接烧器件；
2. ❌ LDO 效率按 90% 估：线性调整，效率约 `Vout/Vin`；
3. ❌ DC-DC 纹波一定大：合理布局与滤波可以做到几 mV；
4. ❌ 电感越大越好：大电感瞬态响应差、体积大、成本高；
5. ❌ 输出电容越大越稳：LDO 有 ESR 稳定区间，DC-DC 要考虑环路；
6. ❌ 只看 datasheet 典型值：要按最坏情况（最高温、最低 Vin、最大负载）设计；
7. ❌ 轻载效率不重要：电池设备大部分时间在轻载；
8. ❌ 电源脚随便接：去耦电容离得远，等于没加；
9. ❌ USB 5V 可以随便取 2A：不枚举/不协商会触发保护或烧线；
10. ❌ 原理图对了就行：电源性能一半取决于 PCB 布局。

## 十一、总结
- 先算压差与发热，再决定 LDO 还是 DC-DC；
- LDO 胜在简单低噪，DC-DC 胜在效率与升压；
- 电感、电容、反馈、保护、时序，一个都不能少；
- 电源是「布局敏感型」电路：热环路小、地去耦好、反馈干净，比堆料更有效。
