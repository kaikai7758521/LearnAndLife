# 以STM32 / ESP32为例 最小系统原理笔记
> 说明：最小系统 = 让芯片**能够上电、稳定运行、可以下载程序**的最简电路，不包含外设驱动。
> 任何 MCU 最小系统都由四大核心模块组成：电源电路、复位电路、时钟电路、下载/调试电路；ESP32 额外包含 Flash 与使能电路。

## 一、最小系统通用概念
单片机最小系统，是芯片脱离外部扩展外设，仅依靠最少元器件，满足芯片正常启动、运行代码的基础电路。
只要缺少其中任意一个核心部分，芯片大概率无法启动、无法烧录程序、运行不稳定。

通用组成：
1. 电源供电 + 电源滤波
2. 复位电路（上电复位/手动复位）
3. 外部高速晶振（可选，芯片内置RC可替代，但精度差）
4. 程序下载&调试接口
5. BOOT启动配置电路（选择启动方式）

## 二、STM32 最小系统（以 STM32F103C8T6 为例）
STM32F103 是经典 Cortex‑M3 内核 MCU，供电电压 3.3V。

### 1. 电源电路
引脚：`VDD`、`VSS`（主电源），`VDDA`、`VSSA`（模拟电源，ADC、PLL）
- 供电：**3.3V**，严禁直接接5V
- 去耦电容（0.1μF 陶瓷电容，每一组 VDD/VSS 就近放置）
  - 作用：滤除电源高频噪声，抑制芯片内部开关带来的电压波动，防止芯片死机、程序跑飞。
- 10μF 电解电容（电源入口）
  - 作用：低频滤波，缓冲上电瞬间冲击电流。
> 规范：每个电源引脚旁边都放一个 0.1μF 瓷片电容，电容尽量紧贴芯片引脚。
> VDDA 模拟电源建议单独加滤波，保证ADC采样精度；可以串一个小磁珠隔离数字噪声。

### 2. 复位电路（NRST 引脚，低电平复位）
经典上电复位 + 手动按键复位：
- 10kΩ 上拉电阻：NRST 默认拉到 3.3V → 正常工作状态
- 0.1μF 电容：上电瞬间电容相当于短路，NRST 短暂拉低，自动上电复位；电容充电完成后恢复高电平
- 复位按键：并联在电容两端，按下直接拉低 NRST，手动复位
> 原理：STM32 检测到 NRST 持续低电平一段时间后，内核复位，所有寄存器回到初始状态；释放后从指定地址启动。

### 3. 时钟电路（外部高速晶振 HSE）
引脚：`OSC_IN`、`OSC_OUT`
- 8MHz 无源晶振（F103常用）
- 两个 20pF 负载电容，分别接晶振两端到GND
- 作用：给芯片PLL提供高精度基准时钟，芯片倍频到72MHz主时钟。
> 可选：不接外部晶振，使用芯片内部HSI 8MHz RC振荡器。缺点：温漂大、精度差，不适合串口通信、USB。

> 内部低速晶振 LSI（内部）：给独立看门狗、RTC；外部32.768K晶振（LSE）是RTC时钟，不属于最简最小系统，可以省略。

### 4. BOOT 启动选择电路
BOOT0、BOOT1 两个引脚，决定芯片启动地址：
| BOOT1 | BOOT0 | 启动模式 |
| ---- | ---- | ---- |
| 0 | 0 | 主闪存启动（正常运行用户程序，最常用） |
| 0 | 1 | 系统存储器启动（ISP串口下载） |
| 1 | X | 内置SRAM启动（调试用） |

电路做法：BOOT0 使用10k下拉电阻默认接地（正常启动），预留排针/按键可以上拉到3.3V进入ISP下载；BOOT1 直接10k下拉接地。

### 5. 下载调试电路
两种方案：
1. **ST‑LINK（SWD，推荐）**：四根线 `SWDIO`、`SWCLK`、GND、3.3V。
   - SWDIO：串行数据
   - SWCLK：同步时钟
   - 优点：仅2根信号线，占用引脚少，支持在线调试、单步断点。
2. **串口ISP下载（USART1）**：PA9(TX)/PA10(RX)，配合BOOT0拉高，使用串口工具烧录。

> STM32F103最小系统元器件清单
> STM32F103C8T6、8M无源晶振×1、20pF电容×2、0.1μF去耦电容×4、10μF电解×1、10k电阻×3、复位按键×1。

## 三、ESP32 最小系统（ESP32‑WROOM‑32 模组）
ESP32 双核 Tensilica LX6，内置 Wi‑Fi+蓝牙；模组自带 SPI Flash，重点是 CHIP_EN 使能引脚。

### 1. 电源电路
模组供电：**3.3V，电流要求更高，峰值可达 300mA+（Wi-Fi发射时）**
- 电源入口：大容量 10μF + 0.1μF 去耦电容
- 关键：ESP32 射频工作电流波动极大，滤波电容不能省；稳压芯片（如AMS1117‑3.3）选型要预留电流余量
> 坑点：直接用单片机IO口给ESP32供电，带载不足会反复重启。

### 2. CHIP_EN（EN）使能引脚
- 10k上拉电阻到3.3V：默认高电平，芯片使能、正常工作
- 可接复位按键拉低：EN拉低时芯片掉电复位，松开上电启动
> 很多新手把EN悬空，芯片随机性无法启动。ESP32没有独立NRST引脚，**EN就是复位控制脚**。

### 3. BOOT 下载引脚（GPIO0）
GPIO0 决定启动模式：
- GPIO0 = 高电平（悬空/上拉）：从Flash启动，运行固件
- GPIO0 = 低电平：进入下载模式（UART下载）
电路：GPIO0 10k上拉电阻，接按键到GND；下载时按住按键上电。

> GPIO2：部分版本需要上拉，一般模组内部已经处理。

### 4. 时钟
ESP32‑WROOM‑32模组**内部已经集成40MHz晶振**，外部最小系统不需要再接晶振！
> ESP32裸芯片ESP32‑D0WD才需要外接40M晶振+负载电容，模组方案不用。

### 5. 下载电路
ESP32 默认 UART0 下载：TX0(GPIO1)、RX0(GPIO3)，搭配自动下载电路（可选）
自动下载电路（增加三极管）：实现串口DTR/RTS信号自动控制 GPIO0 和 EN，不用手动按按键下载；最简最小系统可以省略自动电路，使用手动按键。

### 6. Flash
WROOM系列模组内置4MB SPI Flash，外部不用画Flash电路；裸片方案需要外接SPI Flash。

> ESP32模组最小系统元器件清单
> ESP32‑WROOM‑32模组、0.1μF电容若干、10μF电解、10k电阻×2、按键×2（EN复位键、GPIO0下载键）、AMS1117‑3.3稳压（输入5V时）。

## 四、STM32最小系统 VS ESP32最小系统对比
| 项目 | STM32F103C8T6 | ESP32‑WROOM‑32模组 |
| ---- | ---- | ---- |
| 内核 | Cortex‑M3 | 双核LX6 |
| 典型供电 | 3.3V，电流小 | 3.3V，射频峰值电流大 |
| 复位引脚 | NRST，低复位 | CHIP_EN(EN)，低电平关闭芯片 |
| 启动配置 | BOOT0/BOOT1 | GPIO0 |
| 外部晶振 | 需要外接8M晶振 | 模组自带40M晶振，外部无需 |
| Flash | 内置Flash | 模组自带SPI Flash |
| 调试接口 | SWD(ST‑LINK) | 仅UART下载，无原生SWD调试 |

## 五、常见踩坑总结
1. 去耦电容离芯片太远 → 容易死机、上电不稳
2. ESP32供电能力不足 → 连上WiFi就重启
3. BOOT引脚悬空，电平不确定 → 随机进下载模式
4. 晶振负载电容参数不对，晶振不起振 → 芯片不运行
5. 3.3V和5V混接，直接烧毁MCU
6. ESP32的EN引脚悬空，芯片无法稳定上电

## 六、总结
最小系统电路本质：**给芯片稳定干净的电源，提供复位机制，配置启动地址，提供时钟基准，提供程序烧录通道**。
STM32是传统MCU思路，复位和启动引脚分开；ESP32模组集成度更高，EN兼做复位，GPIO0控制下载模式。
