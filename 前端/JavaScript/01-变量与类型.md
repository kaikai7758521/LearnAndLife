# 变量与类型

JavaScript 是动态类型语言，变量本身没有类型，值才有类型。声明方式有 `var`、`let`、`const` 三种，理解它们的差异是写好 JS 的第一步。

> [!NOTE]
> 这篇笔记记录的是 ES2015 之后的现代写法；浏览器与 Node.js 都已支持。

## 三种声明方式

| 关键字 | 作用域 | 变量提升 | 重复声明 | 推荐场景 |
| --- | --- | --- | --- | --- |
| `var` | 函数作用域 | 提升并初始化为 `undefined` | 允许 | 维护老代码时 |
| `let` | 块级作用域 | 提升但不初始化（TDZ） | 同一作用域不允许 | 需要重新赋值的变量 |
| `const` | 块级作用域 | 同 `let` | 同一作用域不允许 | 默认选择 |

结论很简单：**默认用 `const`，需要重新赋值时用 `let`，不要再用 `var`。**

### 暂时性死区（TDZ）

```js
console.log(a); // undefined：var 的声明被提升
var a = 1;

console.log(b); // ReferenceError: Cannot access 'b' before initialization
let b = 2;
```

块级作用域还体现在循环里：

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log('var', i)); // 3 3 3
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log('let', j)); // 0 1 2
}
```

`var` 只有一个共享的 `i`，而 `let` 每轮循环都会创建新的绑定。

## 原始类型与引用类型

原始类型共 7 种：

- `string`、`number`、`boolean`、`undefined`、`null`、`symbol`、`bigint`

其余都是对象（`Object`、`Array`、`Function`、`Date`、`Map`……）。

```js
typeof 'abc';        // 'string'
typeof 42;           // 'number'
typeof 42n;          // 'bigint'
typeof null;         // 'object'（历史遗留 bug）
typeof undefined;    // 'undefined'
typeof Symbol('s');  // 'symbol'
typeof function () {}; // 'function'
```

判断 `null` 要用 `value === null`，判断数组用 `Array.isArray(value)`。

### 值传递的差异

```js
let a = 1;
let b = a;
b = 2;
console.log(a); // 1：原始类型复制的是值

const obj1 = { count: 1 };
const obj2 = obj1;
obj2.count = 2;
console.log(obj1.count); // 2：引用类型复制的是地址
```

想要「复制一份」需要浅拷贝或深拷贝：

```js
const shallow = { ...obj1 };
const deep = structuredClone(obj1); // 现代浏览器 / Node 17+
```

> [!WARNING]
> `const` 只保证**绑定**不可变，不保证对象内容不可变。`const obj = {}` 之后依然可以 `obj.x = 1`。

## 类型转换的坑

```js
[] + {};        // '[object Object]'
[] + [];        // ''
null + 1;       // 1
undefined + 1;  // NaN
'5' - 2;        // 3（减号强制转数字）
'5' + 2;        // '52'（加号优先字符串拼接）
```

避免隐式转换的办法：

1. 比较一律用 `===` / `!==`；
2. 数字转换用 `Number(x)` 或 `parseInt(x, 10)`，并校验 `Number.isNaN`；
3. 布尔判断用 `Boolean(x)`，注意 `0`、`''`、`null`、`undefined`、`NaN` 都是假值。
